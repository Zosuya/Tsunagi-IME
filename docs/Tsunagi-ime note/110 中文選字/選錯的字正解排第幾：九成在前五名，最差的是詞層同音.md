# 選錯的字正解排第幾：九成在前五名，最差的是詞層同音

漏斗的「差一步」只看**整句切法**是不是第 2 名，選錯的字在**自己那一格**的候選裡
排第幾沒有人量過。這決定修的優先序：大多在前兩三名的，選一次學習層就記住；
常排很後面的才要先修。

## 量法

三批測資外的句子（真人社群貼文 152 句〔本機評估，不進版控〕、新寫的中英 90 句、
另寫的 20 句），走產品的路（`Session::push` 逐鍵推完），把輸出跟期望逐字對到
每一格，對選錯的中文格問 `compose::candidates_for`，看正解排第幾。她／他、
妳／你不算錯；切法就錯、字數對不上的 8 句跳過（那是生成問題不是選字問題）。

## 結果（129 個選錯的字）

| 正解排第幾 | 佔比 |
|---|---|
| 第 2 名 | **59%** |
| 第 3 名 | 17% |
| 第 4～5 名 | 12% |
| 第 6～10 名 | 12% |
| 10 名以後／不在候選 | **0%** |

| 類型 | 佔比 | 排名 |
|---|---|---|
| 詞層同音（程式／城市、視／試、乙級／以及） | 49% | 最分散，第 6～10 名的 15 格有 13 格是這類 |
| 其他單字同音 | 39% | 大多第 2～3 名 |
| 在／再 | 7% | **全部第 2 名** |
| 的／地／得 | 5% | 全部第 2～3 名 |

排最後的：等角**視**圖→試（第 9 名，同一篇出現 3 次）、**乙**級→以（第 8）、
公**式**→勢（第 8）、程**式**→市（第 7，出現多次）。

## 結論

- **在／再、的／地／得 不急**：正解都在第 2 名，選一次學習層就記住——這正是
  [[混淆字與唸音自動修正：再／在這組不做混淆表]] 決定交給學習層的前提，數據支持它
- **最值得修的是詞層同音**：「程式」「視圖」「乙級」是完整的詞，卻被當單字一個
  一個選，正解掉到很後面。可能是詞庫沒收、或切詞沒把它當成一個詞——待查
- 修的優先序：詞層同音 → 其他單字 → 的／地／得、在／再
