# 混淆字與唸音自動修正：`再`／`在` 這組不做混淆表

> **狀態**：功能本身要做，但 `再`／`在` 這一組排除在外（靠學習層）

起點在 [[正解常在第二名：covered 隱形，四個病因都沒過關]]
第 2 個病因（`再`／`在` 分不開）。那一輪跳過的理由是「中文詞庫沒有
詞性」，後來的補量顯示**那只講對一半**。

**📌 未來預定的功能（使用者裁決，2026-09-07）：台灣人分不清的
字與唸音自動修正。**

`再`／`在` 屬於這一類的一部分，但那一類比它大得多——台灣使用者
常混淆的字（`再`／`在`、`的`／`得`／`地`、`做`／`作`、`帶`／`代`、
`以`／`已`）與唸音（`ㄢ`／`ㄤ`、`ㄣ`／`ㄥ`、`ㄓ`／`ㄗ` 不分）。

這不是「修某幾句」而是一個獨立功能：**使用者打錯了也要選對**。
它跟本輪跳過的理由不衝突——跳過的是「靠排序順手解掉」，而這是
正面做一張混淆對照表，那張表是**功能本身**不是例外表。

前置條件：混淆組的來源（人工整理或語料統計）、以及決定它是
「自動修正」還是「候選裡往前排」。動工前要先想清楚後者——自動
修正會動到使用者已經打出來的字，涉及 §2.59／§2.60 那個改寫硬指標。

**2026-09-10 補量（`spike_zaizai`／`spike_learn_zai`）：`再`／`在`
這一組不該做混淆表，因為它跟其餘幾組性質不同。**

查 bigram 對 30 組實際分數：

| 情境 | 對 | 錯 |
|---|---|---|
| 後面接名詞／地點（該用 `在`） | **14** | 0 |
| 後面接動詞（該用 `再`） | **0** | **15** |

「在」全對、「再」全錯，而且不是差一點（`在開`=6.03 對
`再開`=3.88）。**但那不是資料錯誤**——「在＋動詞」是進行式，
中文裡本來就合法：

```text
我在說  ← 正在說話      我再說  ← 再說一次
門在開  ← 正在打開      門再開  ← 再打開一次
```

兩個都對，只是意思不同。語料裡進行式更常見，所以統計必然選「在」。
**這是意圖問題，不是知識問題**——做白名單等於幫使用者猜他想講哪個
意思，猜錯會把現在對的弄壞。

2.61.2 說「卡在詞庫沒有詞性」只講對一半：**就算有詞性也分不出來**，
因為兩邊詞性一樣合法。

**學習層已經解掉了**（實測）：選 **2 次**之後「再確認」「再決定」
「再開始」全部自動對，而且不污染該用「在」的情況（`在台北`、
`現在`、`我在台北` 仍然全對）。要兩次是 §2.22.5.1 那條曲線的
刻意設計——「在」是高頻字，`base × k^N` 選一次翻不動。

**使用者裁決（2026-09-10）：這一類靠資料累積比較好，不做混淆表。**
混淆表留給真正「打錯了也要選對」的組（`的`／`得`／`地` 那種——
使用者是**寫錯字**，不是有別的意思），`再`／`在` 不屬於那一類。
