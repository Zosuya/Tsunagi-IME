# 快捷鍵輔助候選（降低對演算法準確率的依賴）

## 候選層級快捷鍵
- 依信心分數排序給出最可能候選，保留快捷鍵（如空白長按、Tab）切到次選語言候選列表
- 模糊字串（如 ken、kaka）不用賭一個結果，直接兩邊候選都準備好，快捷鍵只是排序切換

## 手動鎖定語境快捷鍵
- 使用者可用快捷鍵明確宣告「接下來這段打日文/英文/注音」，鎖定後續判斷規則
- 比傳統輸入法切換更輕量，只切「本次辨識語言鎖定」而非整個輸入法
- 演算法在鎖定狀態下可跳過辨識層，降低運算負擔、提高候選準確率

## 整體設計原則調整
不追求「一次判斷就對」，改為：
1. 最可能候選排最前面（多數情況免按快捷鍵）
2. 模糊情況下切換候選語言成本要低（一鍵切換，不跳出選單）
3. 使用者可隨時用快捷鍵強制鎖定語境，繞過辨識邏輯
