# 選字按鍵的兩個層次

選字有「未展開」與「展開全部」兩種狀態，**方向鍵在兩種狀態下的
語意不同**：

| | 未展開（列 9 個） | 展開後（多欄網格） |
|---|---|---|
| ↑↓ | 換候選字 | 同欄上下 |
| ←→ | **在字與字之間移動** | 換欄 |
| 空白 | **展開全部** | **收合** |
| Enter | 選中 | 選中 |
| Esc | 離開選字 | 收合 |

## 修掉的問題：左右不成對

原本右鍵綁的是「展開全部」，左鍵是「換格」——結果**選完一格
沒辦法往右移到下一格**，只能靠左鍵繞一圈。

方向鍵四個都留給移動，展開改用空白鍵，左右就成對了。

## 空白鍵是開關

展開之後再按一次空白就收合。原本設計成「展開後變成翻欄」，但那
讓同一個鍵在兩種狀態下做不相干的事；翻欄交給左右鍵就好。

Esc 在展開狀態也是收合，跟空白通到同一個動作——**這不衝突**：
空白是「開關」語意，Esc 是「退回上一層」，兩條路殊途同歸在輸入法
裡很常見。

## 數字鍵在選字模式才是選字

打字時**十個數字全都是注音鍵**（`3467` 是聲調，其餘在大千鍵盤上
也都有對應符號），不能拿來選候選——那會讓 `r4` 打不出來。

但選字模式已經在挑字了，不會再輸入注音，數字就空出來了。這跟
新注音的行為一致。判斷寫在 `keymap::lookup` 的最前面，比字元鍵
更優先。
