# Phase 6（後期）— 跨平台移植

> **2026-09-14 現況**：這篇的 `planned` 指的是 **Linux**。
>
> - **macOS**：已實作完，功能接齊、鍵位表跟 Windows 共用；剩相容性測試清單整份實跑，
>   見 [[macOS 版現況：功能接齊，相容性測試整份通過]]
> - **Linux**：還沒動工。走 Fcitx5 還是 IBus 兩份文件不一致，先不統一

- 核心引擎不動，僅實作各平台整合層與 UI
- **規劃與 spike 進度見 [[macOS 移植：總覽]]**（2026-09-08 真機實測：**引擎確定搬得過去**——漏斗跟 Windows 的基準逐節相同；**輸入法也確定搬得過去**——[[macOS 移植的 spike 排序：先做 Echo 輸入法，五個全部結案]] 排的五個 spike 全部結案：打字（[[spike 2 驗收通過：三種宿主都打得出字]]）、插入點座標（[[spike 4：插入點座標 7 個宿主都拿得到]]）、候選視窗（[[spike 3：候選視窗用 NSPanel]]）、快捷鍵（[[spike 5：快捷鍵攔截]]）。現況地圖在 [[macOS 移植：總覽]] 開頭）
