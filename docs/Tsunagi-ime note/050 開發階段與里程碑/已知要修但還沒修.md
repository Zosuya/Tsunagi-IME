| 項目 | 一句話 | 依據 |
|---|---|---|
| ✅ **擴充包同名 `.bin` 悄悄贏**（09-20 修完） | 判準換成「同一個資料夾不准有兩個同名的包」，不問誰是官方。**這個洞後來真的毀掉一次官方台語包**（91013 行→5 行，授權檔頭一起沒了），閘門因此下沉到 `write_editable` | [[擴充包同名：.bin 悄悄贏、編輯器開到不生效的那份]] |
| ✅ **Mac 按鍵欄拿到國字**（09-20 修完） | spike 否決了原本傾向的修法（宿主根本收不到鍵盤），改成**設定頁舉旗、輸入法送出時改送原始按鍵**。後續又掉出四個坑，都是「那一欄不是普通文字框」的後果 | [[Mac 設定頁的按鍵欄拿到國字：兩平台刻意不一致，撞在一起]] |
| ⏳ **就地編輯按鍵不判重** | 點格子改按鍵沒有 dup 檢查，`invalid_rows` 也不查重複。**但前提變了**：同讀音多輸出做掉之後，「留兩筆」不再等於死資料，要重新評估這還算不算 bug | 同上上 |
| ✅ **同讀音多輸出**（09-20 修完） | 使用者裁定要做。`zh`／`zh_long` 改 `push`＋新增 `zh_all`／`zh_long_all`，長輸出選得回原樣、可設定不自動展開、不進學習層 | 同上上 |
| ✅ **Mac 方向鍵不移動反白框**（2026-09-27 修完、Mac 實機驗過） | 鎖定注音下框還留著時按 `←→`，Windows 往旁邊移一格、Mac 原本回到同一格不動（要按兩下），且會多彈出候選面板。`Action::EnterSelect`／`EnterSelectLast` 改呼叫 `arrow_right()`／`arrow_left()`、拿掉 `open_cands()`，跟 Windows 走同一條 core 路徑。core 加了測試 `arrow不會自己打開候選清單` 守住「只出框不開清單」。**這一項曾被平台稽核判成「等價」，判錯了** | [[Mac 實測翻出五件事：三件是真的洞、一件待確認]]、[[怎麼系統性抓出平台層漏接：解構與 API 反查]] |
| ✅ **Mac 送出時多送了沒成字的注音** | 改一行、六個送出入口一起修好（commit `ca9ec05`），2026-09-27 Mac 實機驗過 | [[Mac 送出時把沒成字的注音也送出去：追了五輪的定位過程]] |
| ✅ **日文半個 mora 送出會消失**（兩平台，裁決 A，`b5445f5`，Mac 實機驗過） | 鎖定日文打 `sush` 直接 Enter，原本 `sh` 憑空消失。裁決：已成字轉假名、沒成字的尾巴原樣字母送出（`sush`→`すsh`）。加 `Session::commit_text()`，Windows 8 個送出入口＋macOS 1 個入口全部換掉，漏斗 0 差異。已合併進 master | [[鎖定日文打半個 mora 直接送出，那幾個字母會消失]] |
