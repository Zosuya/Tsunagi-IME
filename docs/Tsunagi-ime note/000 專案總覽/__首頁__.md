### 一篇該放哪一類

看**「這篇在解決什麼問題」，不是「內文提到什麼」**。

例：「按鍵延遲 p99 從 47.9ms 到 11.9ms」內文全是日文長句（那是測試
素材），但它解決的是效能問題 → `220 效能`，不是 `120 日文`。

跨兩類不用硬選邊：主類別放資料夾，另一類用 frontmatter 的 `相關`
欄位和內文 wikilink 連過去。

## 全部筆記的狀態分佈

```dataview
TABLE WITHOUT ID
  choice(status = "done", "✅ 完成",
  choice(status = "unverified", "🔨 未驗收",
  choice(status = "rejected", "⛔ 不做",
  choice(status = "paused", "⏸ 暫停",
  choice(status = "planned", "⏳ 待做",
  choice(status = "superseded", "🔄 已取代", "❓")))))) AS 狀態,
  length(rows) AS 篇數
FROM ""
WHERE status
GROUP BY status
SORT length(rows) DESC
```
