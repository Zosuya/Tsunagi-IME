# 全半形提示視窗

按 `Shift+空白` 切換全半形時，跳出一個**獨立的**小視窗顯示現在切到哪個
模式（自／半／全），滑動反白＋淡出。

```text
           ┌────────────────┐
           │  自  [半]  全  │  ← 這個視窗
           └────────────────┘
文件區：你好|
           ┌──────────┐
           │ ▶ 你好    │        ← 候選視窗（另一個）
           └──────────┘
```

### 為什麼是獨立視窗，不併進候選視窗

它跟候選是兩件事：候選是「你要選哪個字」，這個是「輸入法現在什麼狀態」。
併在一起的話候選清單的高度會忽大忽小，而且**沒在組字時**得為了顯示它硬開
一個空的候選視窗。分開之後兩邊各自管自己的生命週期，簡單得多。

### 動畫與計時器

TSF 沒有「每一幀叫我一次」的機制——`OnKeyDown` 處理完就沒人會再叫我們。
所以這個視窗自己開 `SetTimer` 每幀重畫（候選視窗的反白滑動也是同一套，
見 [[反白條滑動動畫]]）。

計時器跑在**宿主行程**（記事本、瀏覽器）的訊息迴圈裡，所以動畫要短：
滑動 110ms、停留 500ms、淡出 180ms，跑完就 `KillTimer`。

**Shift 按著時不淡出**——使用者可能還要再按空白切下一個模式，這時候把
提示收掉會讓他看不到自己切到哪。放開才開始倒數。

### GDI 沒有 alpha，淡出靠混色

`FillRect` 那套沒有透明度。淡出是把前景色**往背景色混**模擬的——
不透明度 0.3 就是「三成前景、七成背景」，視覺上等同淡出。
真正的半透明要等 [[spike：Direct2D + DirectComposition]]
的 Direct2D + DirectComposition。

### 字型寫死

標籤「自／半／全」用寫死的字型（見
[[提示視窗字型：商業字型條款擋下，改嵌 OFL 字型的 subset]]），不跟著設定走——
設定頁選的字型只影響候選視窗。這是使用者的決定。
