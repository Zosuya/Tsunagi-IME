# 長內容的換行與捲動

> **狀態**：預覽列捲動永遠貼尾端，選開頭那一格時標記會捲出可視範圍，尚未處理

切法選單的候選常常是整個句子，一定會超過視窗寬度。候選清單與
預覽列的處理**不一樣**：

| | 候選清單 | 預覽列 |
|---|---|---|
| 太長時 | **換行**，那一列變高 | **捲動**，固定一行 |
| 為什麼 | 要看得到完整內容才選得下去 | 打字時視窗忽高忽低很干擾 |

### 候選換行：每列不再等高

原本版面用「行高 × 列數」算高度，換行之後那個假設就破了——
長候選實際佔兩三行，位置跟下一列疊在一起，視窗底部也不夠高。

改法是**每列高度各自量**（`measure_row_heights`），`layout_with`
改成吃「候選清單總高度」而不是列數。`show` 算好存進
`ROW_HEIGHTS`，`paint` 拿同一份來畫——跟 [[版面高度只能有一個算法]] 一樣的道理，
同一個幾何量只能有一個來源。

滑動動畫也要跟著改：滑到兩列之間時**高度也內插**，不然反白塊會
忽然變高。

### 預覽列捲動：顯示尾端

使用者關心的是剛打的字，不是句子開頭。所以預覽列用不換行的
文字格式（`text_format_nowrap`），太長時整段往左推，尾端貼齊
右邊界。

選字標記的位置要扣掉捲動的偏移。**還沒處理的情況**：選的是開頭
那一格時標記會捲出可視範圍——要處理的話得讓捲動位置跟著選字格走，
而不是永遠貼尾端。
