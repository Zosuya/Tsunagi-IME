# 候選一次列九個，編號只畫反白那一欄

兩件事都是同一個原則：**畫面上看得到的東西要跟按得到的東西一致。**

### 4.21.1 從十個改成九個

選字時 `1`～`9` 可以直接挑候選（主鍵盤那排與數字鍵盤都行）——打字時
十個數字全是注音鍵不能拿來選，但選字模式已經在挑字了，數字就空出來，
這跟新注音一致。

問題是候選原本列**十個**，而數字鍵只有九個。第十個在清單上跟其他九個
長得一模一樣（也有編號），卻只能用方向鍵移過去——**看不出差別，就是
陷阱**。`CHAR_PAGE` 與 `CHAR_COLUMN`（展開後每欄）都改成 9。

### 4.21.2 編號只畫在反白所在的那一欄

展開全部時會分成多欄，而數字鍵挑的是「**目前選中那一欄**」的第幾個。
每一欄都畫 1-9 的話，看起來像每一欄都能按，實際上只有一欄有用。

實作上是**位置照留、只是不畫**：把編號換成空字串的話寬度會變 0，
那一欄的候選字就往左移、欄與欄對不齊。
