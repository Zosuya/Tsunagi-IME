# 日文羅馬字音節規則（供 FSM／規則設計參考）

**核心規則**：每個音節（mora）必定以母音結尾（或是 `n`），前面子音數量可變（0～3個字母），並非固定在「第N個字母」。

| 類型 | 範例 | 母音位置 |
|---|---|---|
| 母音獨立 | a, i, u, e, o | 第1位 |
| 單子音+母音 | ka, sa, ta, na, ha | 第2位 |
| 雙字母子音（單一音素）+母音 | shi（し）, chi（ち）, tsu（つ） | 第3位 |
| 拗音（子音+y+母音） | kya, sha, cha, nya | 第3位 |
| 促音（重複子音） | kitte（きって）, kekka（けっか） | 往後推一位 |
| 撥音 n（ん） | 可獨立存在，不需接母音；常打 `nn` 避免歧義（如 kannji vs kanji） | 例外 |
| 長音 | koukou, sensei（母音重複或 ou/ei 表示） | — |

**建議判斷邏輯（FSM 概念）**：
1. 檢查目前字元是否為母音 → 若是，單獨成一個 mora
2. 否則檢查是否為（子音+母音）組合
3. 檢查是否為雙字母子音（sh, ch, ts, ky, ny...）+ 母音
4. 檢查是否為促音（前一字母重複，如 tt, kk, ss, pp）
5. 特例：單獨的 n 或 nn 可獨立成一個 mora

**判斷英日文模糊區的原則**：
- 若字串不符合日文音節 FSM（如出現不合法子音串 `ngr`、`bldk`），可直接排除日文候選，信心度高
- 若字串同時符合 FSM 規則、又是常見英文單字（如 `ken`, `nana`, `kaka`），才需靠字典比對或上下文降低歧義
