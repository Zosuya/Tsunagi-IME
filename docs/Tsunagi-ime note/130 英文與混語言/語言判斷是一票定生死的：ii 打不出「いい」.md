# 語言判斷是一票定生死的：`ii` 打不出「いい」

### 症狀

`rup wu0 g4ek7iiwu0 fu4`（今天是個いい天氣）打出來是 `今天是個ii天氣`。
**切點沒錯**——`ii` 確實自成一段，位置完全正確；錯的是那一段被標成英文。
更麻煩的是使用者**無從糾正**：切法選單裡沒有任何一種把它當日文。

### 根因：`lang_of` 的第二條規則

```rust
// 兩邊都收時，很常用的英文詞也判英文
if crate::english::is_top_word(seg) { return Some(Language::English); }
```

這條規則本身是對的、而且必要——日文詞典 74 萬條，`you`（よう）、
`the`（てぇ）、`time`（ちめ）全查得到，不擋的話英文前 5000 名裡有
145 個會變成假名。

`ii` 的英文排名是 **3557**（大概來自羅馬數字 II），剛好在門檻內，
於是被判成英文。而它同時是很常用的日文詞（いい＝好）。

### 為什麼不能改門檻，也不能分叉切法

- **改門檻**：那 145 個詞會開始被日文搶走，換一個更大的問題。
- **分叉切法**：`Cut = Vec<usize>` **只存切點位置，不存語言**——語言是
  事後由 `lang_of` 對每一段各問一次得出的。要讓同一組切點有兩種語言
  解讀，等於把切法的表示法整個換掉，而 `ALIVE_LIMIT = 400` 那條
  效能界線也會被切法數翻倍直接撞破。

### 解法：改在選字層，不動切點

那一格開放選字，候選清單裡把日文補進去：

```text
#5  ii   ii      ii いい イイ ｲｲ 良い 言い 井伊 …（共 23）
```

判準很窄——**英文段而且日文詞典收得到這個讀音**（`is_japanese_word`）。
清單第一個固定放英文原文，使用者永遠回得來。

**預設輸出完全不動**，所以三支計分器一個數字都沒變
（650/720、4.2%；切點 570/570・560・551）。

### 學起來之後才會變成預設

英文段的選擇記在**英文按鍵原文**底下（`ii`），不是假名。
用假名當鍵的話會跟真正的日文段共用同一格，`you` 就可能被別處學到的
「よう→用」改掉。英文段一定不是合法注音音節（`lang_of` 先問注音），
所以跟注音那條也不會撞。

要選到 `LEARNED`（2）次才生效——「選一次不會突然改變輸出」那條規則
在這裡同樣適用。

### 這類案例有多少：186 個

掃過「英文前 5000 名 ∩ 日文詞典」，共 **186 個**，全都有同一個毛病。
挑幾個實測過的（`是` ＋ 那個詞）：

| 按鍵 | 修好之前 | 現在候選裡有 |
|---|---|---|
| `sake` | 只有 `sake` | 酒・鮭・避け・さけ・サケ |
| `mama` | 只有 `mama` | まま・ママ・儘 |
| `dare` | 只有 `dare` | 誰・だれ・垂れ |
| `zero` | 只有 `zero` | 零・0・ゼロ |
| `mario` | 只有 `mario` | マリオ・まりお |
| `sara` | 只有 `sara` | 更・皿・さら・サラ |
| `oi` | 只有 `oi` | おい・追い・老い・甥 |
| `tara` | 只有 `tara` | たら・鱈・足ら |

純英文句子沒有受影響——`do you like the game` 還是原樣輸出，
只是 `do`／`you` 那幾格變成「可以選字」而已（候選視窗要按了才出現）。

驗過學習那一段：選第 1 次不變、選第 2 次之後 `今天是個いい天氣` 就是
預設了，跟 `LEARNED = 2` 的設計一致。

### 已知取捨：學習是「不看上下文」的

鍵只有英文原文，沒有前後文。所以使用者如果對 `me` 這種**英文用得
比日文多**的詞選了兩次「目」，之後每個英文的 `me` 都會變成「目」。

**它會自己修回來**——把那一格選回英文原文也一樣算表態，次數追過去
就換人（`Index::best` 取次數最高的）。加門檻擋住高頻英文詞是想過的
做法，但那等於推翻使用者連續兩次的明確表態，違反「使用者加的詞無
條件贏過統計」那條規則。先這樣，真的礙事再說。

### 順手修掉的學習污染

`learn::record` 原本以「連續的可選字格」當一段，註解寫著「英文段與
標點不可選字，天然是邊界」。英文段現在可能可選字，那個前提就沒了——
不改的話會記出 `k7ii` → `個いい` 這種跨語言子段，而查詢端
（`word_for` 拿注音鍵、`best_kana_word` 拿假名）永遠問不到它，
只是白白佔掉 `MAX_ENTRIES` 的額度。

改成**語言也當邊界**。順帶清掉一批本來就存在的死條目（相鄰的中文段
＋日文段原本也會被當成同一段）。`bench_learn` 的收斂曲線與改寫率
一個數字都沒動。
