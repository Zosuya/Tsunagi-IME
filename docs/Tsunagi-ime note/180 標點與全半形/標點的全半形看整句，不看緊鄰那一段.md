# 標點的全半形看整句，不看緊鄰那一段

`long` 節從 7／60 跳到 26／60，其餘 16 節全部持平。改的是一個判準：
標點該用全形還是半形，原本問「左邊那一段是什麼語言」，換成問
**「這句話用什麼文字寫的」**。

## 2.59.1 症狀：中文句子裡冒出半形逗號

```
傳server,你好      ← 逗號緊鄰 server，於是半形
你好，你好          ← 逗號緊鄰中文，全形（對）
```

同一份文件裡兩種寫法混用，而使用者並沒有切換語言——他只是在中文句子
裡夾了一個英文詞。

## 2.59.2 病因：判準問錯了問題

`compose_all` 逐段掃描時用 `prev_lang` 記住「前一個非標點段的語言」，
英文段一來就把中日文脈絡沖掉。

但**全形標點屬於句子的書寫系統，不屬於相鄰的詞**。中文文章裡夾用
英文（「用 server 傳，很快」）時逗號仍然是全形——決定它的是這句話
用中文寫，而不是它左邊剛好是英文。英文沒有自己的全形標點體系，
它在這件事上不該有發言權。

## 2.59.3 三個量出來的修正

判準換成「整句的主導 CJK 語言」之後，實測逼出三個修正：

**① 中日並存看誰的段多，不是誰先出現。**
一開始寫成「第一個出現的中日文段說了算」，於是
`我看見那隻鳥，楽しい問題，…` 因為開頭是中文而給 `，`——碰巧對；
但 `美味しい，data 大丈夫 測試…` 開頭是日文就給了讀點 `、`，
而測資期望 `，`。整份測資裡 `|、|` **一次都沒出現**：混語言長句的
主體是中文，日文只是夾用。改成數段數、平手給中文才對得上。

**② `\名字\` 裡面的段不算。**
`e:★` 的按鍵是 `e|:|\|ㄒㄧㄥ|\`，那個「星」是拿來查符號的**鍵**，
不是使用者寫下的句子內容。不排除它的話整句被判成有中文脈絡，
冒號變全形，`symbol` 節掉 1 句。

**③ 只往回看，不往前看——這條是硬指標逼出來的。**
「整句」的直覺實作是掃完全部段落再決定，`long` 因此一度到 30／60
（50%）。但漏斗的**改寫**欄位從 `⚠1` 爆到 `⚠73`：

> `⚠` 後面是「改寫伸到游標 3 格外的次數」，硬指標，必須是 0。

原因是往前看等於「句子後半打出中文時，回頭把前面已經上畫面的
半形標點改成全形」——使用者會看到游標很遠的地方字在跳。改成每個
標點只用「打到它為止」的統計決定，`⚠` 回到 1，代價是 `long` 從
30 退到 24。

**這筆交換是划算的**：30／60 但每打幾個字前文就跳一次，實際體驗
比 24／60 差。分數看不出來的東西才是要看的。

## 2.59.4 測資同步統一了 6 列

程式改對之後，測資裡有 6 列的期望跟新邏輯不一致，全部是同一型
（中日文脈絡已建立在前、標點卻寫成半形）：

| 行 | 段 |
|---|---|
| 583 | `你好\|hello\|,` |
| 1544 | `…わかりました。hello\|,\|，` ← 同一位置連著半形＋全形，自相矛盾 |
| 1554 | `…download，go\|,\|好` |
| 1566 | `hi今天，你好hello\|,\|。` |
| 1567 | `…request成，hi\|,\|今天。` |
| 1574 | `…です，go\|,\|好。` |

行 1544 最能說明這批是生成時的瑕疵：**同一個位置連著兩個逗號，
一個半形一個全形**。

**另外 3 列的期望本身是錯的**：`supermarket，home早…`、
`hello world。update…`、`hello，電車search…` ——這三處的標點**在英文
之間**（左邊是英文，而且前面一個中日文都還沒出現），使用者裁決
「英文之間當然用半形」，所以改的是測資不是程式。改完 `long` 再 +2、
測資稽核歸零。

這一列值得記：**同一個判準會同時管到兩個方向**。「中文句子裡的標點
該全形」跟「英文之間的標點該半形」是同一條規則的兩面，測資原本
兩邊都有寫錯的列。只改自己注意到的那一面，另一面就會在下次改動時
變成假的退步訊號。

## 2.59.5 學到的

- **「看起來對、實測錯」①：** 漏斗總表的「標點／空白錯字率 26.4%」
  是**分母失真**——分隔符空白經 `strip_spaces` 後是 0 字元，827 個
  標點段的錯只除以 163 個字元。按「整段正確」算是 784／827（5.2%），
  跟注音的 3.7% 同一量級。**但在 `long` 節這條線索是真的**：那一節
  43 個字錯全部是標點，日文 102 段、英文 176 段一個字都沒錯。
  總表的比率會騙人，逐節的才不會。
- **分數之外還有指標。** 往前看多 6 句，但改寫警告從 1 到 73。
  只看通過率會選錯。
- **同類型的測資要一起改。** 只改「壞掉的那一句」會讓測資內部
  自相矛盾，下次改動時無從判斷哪個期望才算數。改之前先寫個
  稽核腳本掃全份，確認同型的有幾列。
