# 小數點被當成注音的ㄥ：病因三層，只豁免含小數點的數字串

使用者實測打「看2.64現在可以做什麼」，出來的是「**刊2吽4現在可以做
什麼**」。`2.64` 變成 `2吽4`。

## 2.66.1 只有三個數字會踩雷

`.` 在鍵盤上就是注音的ㄥ，所以 `.` 後面接聲調鍵時剛好湊成完整音節：

| 打的 | 出來的 | 因為 `.x` 是 |
|---|---|---|
| `1.39` | 1**偶**9 | ㄥˇ |
| `1.49` | 1**噢**9 | ㄥˋ |
| `1.69` | 1**吽**9 | ㄥˊ |

`1.5`、`3.14`、`0.5`、`v2.0` 都是**對的**——`.5`（ㄥㄓ）湊不成音節，引擎
自然不收。純數字（`264`、`12345`、`2026`）也全對，**問題不在數字，在
小數點**。

測資裡「數字.數字」的樣式**一筆都沒有**（只有註解行有），所以這個洞
一直沒被量到。

## 2.66.2 病因三層

**第一層：`swallowed`（吞標點）。**正解 `英:2.64` 因為含 `.` 被
`clean_word` 判定不乾淨，記一次 `swallowed`；而 `英:2|注:.6|英:4` 是 0。
`swallowed` 排第 3 順位，正解直接輸掉。

修法是在 `clean_word` 加例外——**數字包夾的小數點不算標點**，跟既有的
撇號（`don't`）、長音符號（`fo-ku`）是同一種寫法。判準要求**兩側都是
數字**，所以 `5.␣`（第 7 週，`.` 是注音的一部分、後面接空白）不受影響。

**第二層：`prune` 沒放行（切法根本沒生成）。**修好第一層之後
`誤差0.49公尺` 仍然壞，而且查下來 **16 種候選裡沒有一個含 `英:0.49`
整段**——那條切法在生成階段就死了，排序再怎麼調也救不回來。

原因是 `prune` 的「純數字段自成一段」那條只認 `is_ascii_digit`，
`0.49` 含小數點不符合，於是掉到 `english_word_ok`：不是英文詞、不是
合法注音／日文、不是縮寫、也不在結尾 → 判死。修法是把那條判準擴充成
允許數字包夾的小數點，跟第一層同一個判準。

> 這條規則的註解本來就記著同一個病的前一次發作——`number` 節曾有 74 句
> 因為「數字自成一段」生不出來。小數點是它的下一個變形。

**第三層：`passthrough`（英文殘渣）。**切法生得出來之後還是輸：
`英:0.49` 整串不是英文詞，被罰 4 分，輸給 `英:0|注:.4|英:9` 的 2 分。

修法要**只豁免含小數點的數字串**。第一次試的是「所有純數字串都豁免」，
單獨打 `0.49` 確實對了，**但漏斗淨退 6 句**：

| 節 | 不豁免 | 全部數字都豁免 |
|---|---|---|
| `en_bopomofo` | 46 | 44（-2） |
| `holdout` | 86 | 84（-2） |
| `zh_sentences` | 85 | 83（-2） |
| `kana_fragment` | 41 | 40（-1） |
| `number` | 80 | 81（+1） |
| **總計** | **1278** | 1272（**-6**） |

純數字串在句子裡會變成「免費的分隔符」，把本來該連在一起的注音段拆開。
**只豁免含小數點的**就沒這個問題——`0.49` 這種東西沒有別的解讀，而
`264` 有。

> **教訓：單獨打對了不代表句子裡對。**第一次試第三層時只量了單獨的數字
> 串就下結論，沒重跑漏斗——退步全被蓋住。跟 §2.65 的 `rank_diff` 想解的
> 是同一個問題：總數不變也可能是修好 10 句弄壞 10 句。

## 2.66.3 結果

漏斗 1264→**1280**（+16），零節退步。`regression` 節的錯字率從 40.3%
降到 2.8%。

| | 修前 | 修後 |
|---|---|---|
| `2.64`／`1.39`／`1.49`／`1.69`／`0.49` | 2吽4、1偶9、0噢9… | ✅ 全對 |
| `誤差0.49公尺` | 誤差0噢9公尺 | ✅ |
| `圓周率3.14` | ✅ | ✅（同句兩種 `.` 都對） |
| `第7週`（`5.␣`）、`下午3點` | ✅ | ✅ 沒被誤傷 |
| `看2.64現在可以做什麼` | 刊2吽4現在… | 刊2.64現在…（**數字對了**） |

使用者原本回報的那句，數字部分已經正確，剩下的「看→刊」是選字排序
問題（「看」排第 3），跟小數點無關，另案。`大約1.69倍` 的「倍→備」
同理。兩筆都留在 `regression` 讓它紅著。
