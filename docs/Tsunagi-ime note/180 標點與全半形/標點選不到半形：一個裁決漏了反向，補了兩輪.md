# 標點選不到半形：一個裁決漏了反向，補了兩輪

`variants` 的設計原則「只給不用 Shift 的鍵」與「打 `!` 就是要驚嘆號」
這兩個裁決都只想到「要不要轉全形」，**漏了反向**：`Auto` 模式下中文旁邊
會自動轉全形，而沒有候選就**沒有回頭路**，使用者得刪掉重打。
第一輪補了 `, . ;` 三個；第二輪才發現同一個病還有五個 Shift 標點
（`: ? ! ( )`）——**洞開了兩次**，因為第一輪的測試只檢查那三個鍵本身。
第三次補的測試改成守**性質**：`Auto` 轉出來的全形一定要在候選裡找得到。

## 試過的路

### 一、逗號句號分號選不到半形（原 2.63）

使用者實測：「這個傳給api，這樣知道了嗎」——中間那個逗號想要半形，
**候選裡沒有**。`variants` 那張表對 `,` 只列了 `，、；` 三個全形。

#### 這是遺漏，不是設計

同一張表裡 `/` 與 `-` **本來就把半形放在候選第一個**：

```rust
'/' => &['/', '／', '？', '・'],
'-' => &['-', '－', '—', '～', '‧'],
```

而 `, . ;` 三個全部沒有半形。`variants` 自己的文件也說得很清楚：

> 使用者想要哪一種引擎猜不到，而**猜錯的代價是使用者得刪掉重打**
> ——那正是選字要解決的問題。

中文句子裡夾 API 名稱、網址、程式碼時要的就是半形，這正是「猜錯」
的情況。

#### [[標點的全半形看整句，不看緊鄰那一段]] 讓它更容易被踩到

改判準之前，英文旁邊的標點**預設就是半形**（看緊鄰那一段），所以
使用者不太需要選。改成看整句之後，中文句子裡的標點一律全形
——這對「傳server，你好」是對的，但對「傳給api,」就需要能選回半形，
而那個選項不存在。

**一個修正把另一個缺口暴露出來**：原本的錯誤行為剛好掩蓋了缺少的
候選，改對之後才顯出來。

#### 修法與怎麼鎖住

半形補進 `, . ;` 的候選，**擺最後**——預設維持全形（中文句子裡那是
對的），只是選得到。

**鎖它的是單元測試不是測資**：漏斗量的是「預設顯示什麼」，而這個 bug
在「候選裡有沒有」。測資加一筆 regression 鎖不住它——預設沒變，測資
看不出候選少了東西。`variants` 原本一個測試都沒有，這次補上。

> 這一條值得記：**修好的東西要用對的工具鎖**。漏斗不是萬用的網，
> 它量不到的維度（候選清單、學習層、視窗定位）得各自有測試。

### 二、Shift 系列的標點選不到半形（原 2.68）

使用者回報「`：` 沒有半形」，檢查之後發現**同一個病有五個**。

#### 盤點：五個 Shift 標點都沒有回頭路

| 鍵 | 中文旁邊變成 | 候選數 | 選得到半形？ |
|---|---|---|---|
| `:` | ： | 0 | ❌ |
| `?` | ？ | 0 | ❌ |
| `!` | ！ | 0 | ❌ |
| `(` | （ | 0 | ❌ |
| `)` | ） | 0 | ❌ |
| `, . ; / -` | ，。；／－ | 3～5 | ✅（上一節修過） |

病因是 `variants` 的設計原則「只給不用 Shift 的鍵」——那是 2026-09-04
的裁決，理由是「打 `!` 就是要驚嘆號，意圖明確不必再選」。

**那個裁決只想到「要不要全形」，漏了反向**：`Auto` 模式下中文旁邊會
自動轉全形，而沒有候選就**沒有回頭路**，使用者得刪掉重打。踩到的情境
跟上一節修的逗號句號一模一樣——中文句子裡夾程式碼、網址、API 名稱、
時間（`參數:值`、`func()`、`真的?`）。

#### 修法與一個被借用的判準

這五個各給**兩個**候選：全形（預設，中文句子裡那是對的）與半形。不像
`[` 列一整排——括號真的有七種寫法要挑，冒號只有全半形之分。

改完之後有個測試掛了：`標點在鎖定時仍自成一段` 斷言「驚嘆號該是**不可
選字**的獨立一段」。但那個測試真正要守的是「標點不被拿去查詞庫、要自成
一段」，它只是**借用 `selectable == false` 當判準**——因為當時驚嘆號剛好
沒有候選。判準改成 `is_mark` 並補上「標點格的文字就是標點本身」，性質
守得更準。

## 根因：判準要守性質，不要守個案（原 2.68.3）

上一節那次的測試只檢查「按鍵本身的半形在不在候選裡」，所以這五個鍵
一個都沒被涵蓋——**洞開了兩次**。這次補的第三個測試改成問**性質**：

> **`Auto` 轉出來的全形，一定要在候選裡找得到。**

它掃過所有標點鍵，凡是在中文旁邊會被轉成全形的，就要求選得回半形。
未來加新標點會自動被守住，不必記得補測試。

結果：漏斗 1280 持平、539 個測試全過。
