# 從輸入法裡開設定頁：↑↑↓↓ 手勢與輸入法選單

設定頁在 macOS 上編得起來、跑得起來之後，剩下的問題是**怎麼叫它**。
Windows 有兩條路（語言列的右鍵選單、組字時的 ↑↑↓↓ 手勢），macOS 兩條
都補上了，而且**指令的判斷邏輯完全共用** `ime_core::command`——平台層
只負責把方向鍵翻成 `Dir`、把 `Command` 執行掉。

### 手勢：三條出路，跟 Windows 一字對一字

打字中按 ↑ 或 ↓ 不再直接進選字，先過 `Gesture`：

| 情況 | 做什麼 |
|---|---|
| 組字內容**不是指令** | 手勢清掉，當普通方向鍵（進選字＋開清單） |
| 湊滿 ↑↑↓↓ | **取消**組字（不送出），執行指令 |
| 還有希望湊成 | 這一下先吃掉，什麼都不做 |

第三條是關鍵，Windows 第一版正是敗在這裡：**進了選字模式方向鍵的意義
就變了**（變成移動反白），手勢再也收不到第二下。所以 `promising()` 存在
的唯一理由就是「這一下先別進選字」。

隔 1500ms 沒有下一下就算放棄（`GESTURE_TIMEOUT`，跟 Windows 同值）——
使用者按了 ↑↑ 然後改變主意，那兩下不該留著等下次的 ↓↓ 來湊。

`ToggleEngine` **一定要寫回 `config.toml`**：`settings::refresh()` 每兩秒
重讀一次設定檔再套回 session，只改記憶體的話下次重讀就被蓋回去，症狀是
「關掉了，過幾秒又自己開回來」（Windows 那邊的原話）。macOS 這邊寫完
直接整份重載——檔案是唯一的真相，重載一次就不必自己維護時間戳。

### 輸入法選單：`showPreferences:` 是 IMK 的慣例

覆寫 `IMKInputController` 的 `menu` 回一個 `NSMenu`，選單項的 action 設成
`showPreferences:`，**IMK 就會自動呼叫控制器的同名方法**，不必自己接
target/action（IMK 標頭上寫著這條）。這條路同時補上了 macOS 缺的
「發現得到」——Windows 是靠候選列底下那行 `↑↑↓↓ ⚙ 開啟設定` 的提示，
macOS 的面板目前沒有提示列，暫時由選單列頂替。

### 設定頁裝在哪：`Contents/Resources/ime_settings`

跟輸入法**一起裝、一起走**，`paths::settings_exe()` 就是去那裡找。
`build-app.sh` 加了 `--all`（對應 Windows 的 `-All`）只決定**要不要重建**
它；既有的執行檔照樣複製進去，不然平常建輸入法會把設定頁弄不見。

簽章有個順序要注意：**`--deep` 只處理巢狀的 bundle**，`Resources/` 底下
一支裸的 Mach-O 不歸它管。先簽那支、再簽外層，外層的資源封印才蓋得到它。

### 打開一看全是豆腐方塊：字型路徑寫死在 Windows

第一次在 Mac 上開設定頁，整個介面的中文變成方塊——使用者的回報是
「編碼有問題」。**跟編碼無關**：egui 內建字型本來就沒有中文字，
`install_cjk_font` 靠系統字型補上去，而那份候選清單三條全是
`C:\Windows\Fonts\…`，在 Mac 上一支都讀不到就 `return` 了。

改成依平台給候選，而 macOS 這邊有個坑：

- **`/System/Library/Fonts/PingFang.ttc` 在新版 macOS 上不存在**。蘋方搬進
  了 `AssetsV2` 的資產目錄，路徑中間有一段雜湊（這台 macOS 26 是
  `com_apple_MobileAsset_Font8/86ba…/AssetData/PingFang.ttc`），**每台機器、
  每次系統更新都可能不同**，寫死一定會壞。所以掃兩層目錄去找它
- 退路用 `/System/Library/Fonts/` 底下路徑穩定的 `Hiragino Sans GB.ttc`
  與 `Supplemental/Songti.ttc`
- **字型集合一定要指定字面編號**：蘋方那個檔裡有 24 套（HK／MO／TC／SC
  各六個字重），字面 2 才是 `PingFangTC-Regular`；不指定拿到的是 HK。
  宋體則是字面 7 才是 `STSongti-TC-Regular`

原本的程式碼只有預覽區在設 `FontData::index`，介面字型那份沒設——在
Windows 上剛好無所謂（`msjh.ttc` 的字面 0 就是要的那個），到 macOS 就
差很多。
