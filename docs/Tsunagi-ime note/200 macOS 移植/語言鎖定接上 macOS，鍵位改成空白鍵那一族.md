# 語言鎖定接上 macOS，鍵位改成空白鍵那一族

原本裁定「macOS 不做語言鎖定，要鎖定就回頭用系統內建輸入法」。**後來發現
台語綁在它上面**——`Session::tw_mode()` 是 `lock == Bopomofo && any_tw()`，
段選單裡所有台語的分支都走這個閘門。不做鎖定就等於 macOS 永遠用不到台語，
所以補回來。

### 鍵位：`Shift+空白`＝鎖定、`Cmd+Shift+空白`＝全半形

| 組合 | 做什麼 |
|---|---|
| 空白 | 注音一聲（組字中）／普通空白（沒組字） |
| **`Shift+空白`** | **語言鎖定輪替**（自動 → 注音 → 日文 → 英文） |
| **`Cmd+Shift+空白`** | **全半形三態**（自動 → 半形 → 全形） |

跟 Windows 的「單按 Ctrl」不同，原因在下面。兩者共用同一個提示面板——
`core::render::width_bar` 本來就備好語言那組標籤（`lang_options` 會依設定
過濾掉停用的引擎），Windows 那邊也是一個視窗服務兩件事。

### 為什麼不能照抄 Windows：`Ctrl+…` 到不了輸入法

這是量出來的，不是推論。`keyprobe.log` 累積 154KB、涵蓋 spike 5 那輪完整的
快捷鍵量測：

| 組合 | 進到輸入法的次數 |
|---|---|
| `Cmd+V` | 23 |
| `Cmd+A` | 5 |
| `Cmd+C` | 4 |
| `Cmd+Shift+空白` | 50 |
| **任何 `Ctrl+…`** | **0** |

macOS 把 Ctrl 系當成應用層／系統層的指令事件，IMK 不轉給我們。

### 我在這裡犯的錯：只驗了一半

第一次選的是 `⌃⇧空白`，理由是查了 `com.apple.symbolichotkeys`——**0 個系統
快捷鍵在用它**。看起來很有說服力，但那只回答了一半的問題。

> 挑組合鍵**要分開驗兩件事**：
> 1. 系統快捷鍵有沒有佔用它（查 `symbolichotkeys`）
> 2. **它到不到得了我們**（只能靠 `keyprobe` 實測）

[[spike 5：快捷鍵攔截]] spike 5 的教訓是「**到得了**跟**該不該吃**是兩件事」；我這次踩的是
它的反面——**沒佔用**不等於**到得了**。

順帶記下這台機器上空白鍵的佔用情況（`symbolichotkeys` 實測）：`⌃空白`＝選取
上一個輸入來源（啟用）、`⌘空白`＝Spotlight（啟用）、`⌥⌘空白`＝檔案搜尋
（啟用）；`⇧空白` 與 `⌘⇧空白` 都沒被綁。

### 第二個錯：判斷寫在放行之後

`Cmd` 系在 `on_key` 裡是**整批讓回宿主**的（[[spike 5：快捷鍵攔截]] 的決定，不然複製貼上
會被吃掉）。全半形要挖一個洞出來，**那個判斷必須寫在放行之前**——我註解裡
寫著這句話，程式卻放在 40 行之後，於是 `Cmd+Shift+空白` 全部被讓回去。

`keyprobe` 一眼看穿：**50 筆全是「放行」**。那條 log 這次省下的時間比寫它
的時間多。

### 為什麼不用「單按 Ctrl」那條路（就算 Ctrl 到得了）

即使不考慮上面那條，單按修飾鍵在 macOS 也有兩個代價：

1. 修飾鍵走 `flagsChanged`，**IMK 預設不送**——要放寬 `recognizedEvents:`。
   而文件寫著：只回 `NSKeyDownMask` 的輸入法，使用者點在組字區外面時系統
   會自動送 `commitComposition:`；**放寬之後就沒有了**，得自己收 `leftMouseDown`
   補回來（相容性測試清單的 C23）
2. **會誤觸**：`⌃空白`（切輸入來源）被系統攔走，我們收不到那個空白鍵，
   Ctrl 一放開就誤判成單按

帶第三個鍵就沒有這些問題——它是正常的 keyDown，**收不到就是收不到**，
不會誤判成別的東西。實作上也少了一整套狀態機。

> 一度真的把 `flagsChanged` 那套寫完了（`recognizedEvents:` 放寬、
> `leftMouseDown` 補償、`ctrl_used`／`ctrl_down` 狀態機），使用者改用組合鍵
> 之後**全部拆掉**。留這段是想記住：**先問「這個平台的事件模型允許什麼」，
> 比照抄另一個平台的互動便宜得多**。

### 台語現在通了嗎

機制通了，**但這台機器沒有台語包**（資料不進版控，9 萬多筆的外部檔案）。
要用的話照 `tools/取台語資料.md` 下載建包，那兩步在 Mac 上照樣跑得動。
包裝好之後鎖定注音就會進入台語模式：反白單位變成「詞」、`←→` 跳詞、
`Shift+←→` 調寬度。
