# 重裝之後要切走輸入法再切回來

> **狀態**：病因是推斷不是確認（回報時症狀已消失），判準「是不是剛重裝完」待下次真機復現驗證

實測回報「打你好跳不出段選單，過一下又可以了」。核對過 core（`seg_open`
之後有 6 個候選）與 `on_key` 的分派順序，兩邊都沒問題。

最合理的解釋是**行程換過但宿主還連著舊的**：`build-app.sh` 會 `pkill` 舊
行程再 `open` 新的，宿主手上那條連線在那一瞬間就斷了，而它不一定會自己
接到新行程。症狀是「剛改的東西沒生效」或「本來會的功能突然不會了」。

**這是 macOS 版對應 Windows 那條「驗證新版必須讓宿主整個行程重開」的
坑**，只是解法不同——macOS 不必關掉宿主，切走輸入法再切回來就會重新
連線。`build-app.sh` 的收尾訊息加了這一行提醒。

> 沒有當場抓到證據（回報時症狀已經消失），所以這是推斷不是確認。
> 再遇到的話要記下**是不是剛重裝完**——那是判準。
