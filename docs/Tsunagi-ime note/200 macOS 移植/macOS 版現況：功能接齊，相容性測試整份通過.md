# macOS 版現況：功能接齊，相容性測試整份通過

[[macOS 移植：總覽]] 記的是 2026-09-08 的結論：五個 spike 做完，**剩下的是實作不是可行性**。
這篇接在後面，記 2026-09-14 盤點時實作做到哪、還差什麼。

**判準**：程式碼上沒有非做不可的缺口了。

> **2026-09-15 [[相容性測試清單_macOS]] 整份實跑通過**：TextEdit 全套 C1～C28、
> 其他 9 個宿主的短版（含 Safari／終端機／Chrome 的密碼欄）、崩潰隔離 G1～G3、
> 設定與資料 S1～S9、安裝登記 R1～R5（先移除再從零安裝）。
> 跑的過程中翻出兩個**引擎**的錯、當場修掉並複測：段選單定案後按倒退鍵整句跳回
> （`a2ad6ee`）、大寫字母被當成注音（`cdb2593`）。兩個都在 core，Windows 一起受惠。
> **沒涵蓋的**：`.pkg` 安裝包在乾淨帳號上的安裝（詞庫包進 bundle、Gatekeeper），
> 那屬於發布流程，見 [[macOS 的建置與發布流程]]。

### 發布前要決定的

- **簽章**：自己用 ad-hoc 就夠；發給別人才需要 Developer ID（[[macOS 移植的六項待決：四項裁決，不做語言鎖定一天就推翻]] 第 4 項）
