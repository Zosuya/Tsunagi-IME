# 附件

筆記裡的截圖、錯誤訊息、示意圖放這個資料夾。

## 怎麼引用

```markdown
![[註冊失敗的錯誤訊息.png]]
```

**用 wikilink 形式，不要寫相對路徑**——`![](../../_附件/xxx.png)` 在筆記
搬資料夾時會斷掉，而這個 vault 的分類還在調整。wikilink 只認檔名，搬到
哪裡都連得到。

## Obsidian 要設定兩處

設定 → 檔案與連結：

- **附件預設位置** → 「在下方指定的資料夾」→ `_附件`
- **內部連結類型** → Wikilink

設好之後直接把圖貼進筆記，Obsidian 會自動存到這裡並插入正確的連結。

## 這裡不放什麼

**產品素材留在 repo 根目錄的 `DOC/`**——icon、主視覺、demo 用的 gif 與
mp4 是給 README 和 Release 用的，不是筆記的一部分。那些 mp4 有幾十 MB，
放進 vault 只會讓 Obsidian 白白索引。

| 類型 | 放哪 |
|---|---|
| 筆記的插圖（截圖、示意圖） | `docs/Tsunagi-ime note/_附件/` |
| 產品素材（icon、demo gif／mp4） | `DOC/` |
