# 被否決：罰夾在注音中間的短英文碎片會打壞 ii（いい）

`這種情dj盎就是藥用` 是另一種長相——`dj` 兩個字母卡在中文正中間。
想加一條「兩邊都是注音段的短英文碎片就罰」，**三支計分器都沒動，
卻打壞了一個不在測資裡的案例**：

```text
今天是個ii天氣  →  今天是個iiwu安氣
```

`ii`（いい）正是 §2.24 剛修好的東西——它就是「夾在中文中間的兩字母
英文段」。**兩條規則從按鍵上分不出來**，所以這條直接否決。

留下的教訓：**這一類是打地鼠**。壓掉一種長相，下一種就浮上來
（`這種情況就是ul4m/4`）。要真的清乾淨，方向應該是「選單只顯示
通過品質閘門的那幾列」，而不是一條一條加排序判準——那是另一件事，
先記著。
