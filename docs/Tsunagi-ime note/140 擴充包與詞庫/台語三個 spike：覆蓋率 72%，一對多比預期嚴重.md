# 台語三個 spike 的結果

工具：`core/src/bin/spike_taigi_cover.rs`，資料 `ChhoeTaigi_iTaigiHoataiTuichiautian.csv`
（19,775 筆，CC0）。**這支不是計分器**，是一次性的可行性量測，跟 `check_*`
那幾支不同層級。

**一、覆蓋率：72.0%，比預期低但可用**

判準借 `mkkeys` 的三個記號：按鍵**產得出來**不算數，要能**打得回原詞**才算。

| | 條數 | 佔比 | 意思 |
|---|---|---|---|
| 命中 | 7,135 | 56.3% | 整詞查得到詞表讀音，引擎第一名就打回原詞 |
| 逐字拼✓ | 1,991 | 15.7% | 詞表沒收整串，但逐字拼剛好對 |
| **可用小計** | **9,126** | **72.0%** | **B 路線真正能用的量** |
| 排序輸 | 336 | 2.7% | 按鍵對，引擎打出別的詞（`上尉`→`尚未`） |
| 逐字拼✗ | 3,210 | 25.3% | 詞表沒收，而且真的拼錯 |
| 查不到 | 6 | 0.0% | 連 `BPMFBase` 都沒有（`网络`、`水𰹬`） |

分母是 12,678 個去重後的純漢字華語詞（原始 19,042 筆，一詞多台語詞去重）。
另有 451 筆含英數（`FB`、`7-11`、`Python`），B 路線先不處理。

**「逐字拼」不等於錯，這件事要分開數。**第一版把 41% 全算成不可靠，但
例子是「一個星期」「一卡通」——由常見詞組成的複合詞，詞表沒收整串，逐字
拼剛好對。分開之後真正拼錯的只有 25.3%，而且**失敗的幾乎都是諺語整句**
（「一山還比一山高」→「衣衫還比衣衫高」、「一得一失」→「醫德醫師」）。

依詞長看，真正像「詞」的那批表現好得多：

| 詞長 | 總數 | 可用率 | |
|---|---|---|---|
| 1 字 | 309 | 32.7% | 最低，但都是`亨`／`冉`／`卉`／`卅`這種冷僻字，本來就要翻頁選 |
| 2 字 | 5,651 | 77.1% | |
| 3 字 | 3,556 | 69.0% | |
| 4 字 | 2,408 | 75.8% | |
| **1～4 字小計** | **11,924** | **73.3%** | |
| 5 字以上 | 754 | 6～59% | 多半是諺語整句，拿掉也不影響大局 |

**二、資料乾淨度：97.3% 純漢字，比預期好很多**

擔心的「他們；他人」那種多義**一筆都沒有**（分號 0 筆），括號註解也沒有。

| | 筆數 | 佔比 |
|---|---|---|
| 乾淨純漢字 | 19,234 | 97.3% |
| 含英數 | 420 | 2.1% |
| 含逗號（諺語整句） | 121 | 0.6% |

清洗規則只要兩條：濾掉含英數的、濾掉含標點的。**不需要寫多義切分**。

**三、字型：1.4% 的詞含擴充區字，不是障礙**

台語漢字逐詞看，98.6% 完全落在 BMP（基本區＋擴充 A），只有 278 個詞
（1.4%）含 BMP 外的字，**總共只有 42 種字**。最常見的是 `𡳞`(49)、
`𠢕`(29)、`𨑨`(22)、`𤆬`(20)。

[[台語輸入法：三種解讀、資料盤點與產品形態]] 2.64.4 舉的 `𪜶` 確實在擴充 B（U+2A736），但 `毋`(U+6BCB)、`袂`(U+8882)、
`佮`(U+4F6E) 這三個常用字都在基本區，沒有問題。

**42 種字是可以逐一驗的規模**，不必把整批當風險。實機驗證（候選視窗真的
畫得出來嗎）還沒做，那要等實作到能打字才驗得了。

**四、意外發現：一對多比預期嚴重（原本沒列進 spike）**

平均一個華語詞對 1.47 個台語詞，聽起來不痛不癢，但長尾很兇：

```
獨角仙 → 兜蟲／戰甲蟲／柴龜／樹龜／牛屎龜／犀角金龜／獨角仙／…（15 個）
以後   → 別日／別日仔／將來／尾仔／尾手／後來／後日仔／…（14 個）
小氣   → 㾀屎／凍霜／孤佬／小鄙臉／澀／菝仔屎／虯／…（12 個）
```

分布：1 個 9,699 詞、2 個 2,034、3 個 690、4 個 294、5 個 136、6 個 70、
**7 個以上 129 詞**。

[[台語輸入法：三種解讀、資料盤點與產品形態]] 2.64.7 說「一對多沒有正解，列出來讓使用者選」——那是對的，但**沒料到
會多到 15 個**。候選視窗塞不下，得先決定取捨規則（見待決事項 5）。
這個數字也讓 2.64.8 第 2 項的天平往「鎖定模式」再偏一點：混進候選的話，
打「以後」會多出 14 個台語候選，平常打華語的人會被淹沒。

**踩到的坑：spike 少載了詞庫，命中率印出 0.0%**

第一版沒抄 `mkkeys` 那段資料載入（`dict::load_bopomofo` 等六行），中文
詞庫沒載，引擎把注音按鍵全判成日文——`一一` 打出 `う u`。`mkkeys` 原始碼
那段的註解早就寫了「少載任何一層，這支的『OK』跟計分器的結果就會各說
各話」，**照抄一支既有工具時，最該抄的就是那段看起來像樣板的初始化**。
