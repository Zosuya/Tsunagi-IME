# 風險清單與對策

| 風險 | 影響 | 對策 |
|---|---|---|
| TSF 學習曲線導致 Phase 0 卡關 | 全案延宕 | 先讀 weasel / khiin-rs 原始碼；Phase 0 給足時間盒，超過 4 週改用 C++ 官方 sample 為殼 |
| 語言誤判率高於預期，UX 不如手動切換 | 產品價值不成立 | Phase 2 就建評測集量化；快捷鍵覆蓋/鎖定機制（Phase 3）是保底，確保最差情況等同傳統輸入法 |
| 英日模糊區（`ka`, `ken`…）無法可靠區分 | 日文體驗差 | 接受模糊、雙語候選並列 + Tab 切換；上下文先驗 + 個人回饋學習逐步收斂 |
| Electron/遊戲相容性問題 | 使用者流失 | ✅ 測試矩陣已建（`相容性測試清單.md`）；逃生口是**鎖定英文＋半形**——那個狀態完全不組字、直接進文件，語意等同關掉輸入法，見 [[語言鎖定：單引擎模式]]。崩潰隔離另提供自動的單鍵降級 |
| 詞庫授權污染 | 無法發佈 | ✅ 已盤點結案，見 [[發布前的授權盤點：資料比程式碼難]]。五個來源只有教育部字頻受限（CC BY-ND），可散布但**不得修改內容**——2026-09-12 它連同另外三份小原料進了版控，見 §2.20.6 |
| 未簽署被企業環境擋 | 部署受限 | ✅ 調查完成，走開源免費方案，見 [[Code signing：第一版先不簽，公開後再申請開源免費簽章]] |
