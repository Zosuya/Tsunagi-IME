# 三語言組合（注音／英文／日文）的具體分析

### 注音 vs 英文：衝突低
- 標準注音鍵盤有固定鍵位對應注音符號，與英文字母映射完全不同
- 可先用「按鍵本身」做特徵判斷，不需辨識輸入內容
- 難點：模糊按鍵組合（如 `ru` 既是注音組合也是合法英文開頭），需靠詞頻/上下文判斷

### 日文 vs 英文：衝突較高
- 日文若用羅馬字輸入（Romaji → かな），本質上是用英文字母打日文，無法只靠按鍵區分
- 例：`ka` 可能是日文か，也可能是英文 car 的開頭
- 需等到音節終止（母音結尾、促音、撥音等規則）才能較有信心判斷，或搭配字典比對

### 日文 vs 注音：衝突低
- 兩者按鍵集合重疊度低，主要衝突集中在「日文 vs 英文」這組
