# 輸入層拆三條路：自動、鎖定注音、鎖定日文

鎖定注音之後的互動要跟新酷音一致，而那**跟自動辨識是兩套不同的
輸入邏輯**——不是同一套的兩種參數。所以輸入層拆開了。

```text
  按鍵
   │
   ├─ Cascade（自動）────── 累加式切法 → 排序 → 多種切法可選
   │                        不知道是哪個語言，每種可能都留著
   │
   └─ BopomofoInput（鎖定注音）─ 四格音節緩衝 → 一種切法
                                已經確定是注音，走新酷音那套
   ↓ 兩者都產出 Vec<Vec<Segment>>

  選字、詞庫修正、全半形…（`session` 的其餘部分，兩邊共用）
```

檔案是 `core/src/input.rs`。

### 為什麼非拆不可

| | 自動（Cascade） | 鎖定注音（BopomofoInput） |
|---|---|---|
| 按鍵累積 | 字串追加 | **四格覆寫**（打錯聲母直接改） |
| 組字區顯示 | 原始按鍵 `su3` | **注音符號** `ㄋㄧ` |
| 切法 | 多種，可選 | 只有一種 |
| 何時算完一個單位 | 不知道（使用者自己決定） | **按到聲調鍵** |

一開始是在 `Session::push()` 裡用 `if` 分流，但那讀起來像「一個引擎
有兩種模式」，實際上是兩套規則。使用者要求結構上真的分開。

拆完有個現象可以驗證它是乾淨的：`session.rs` 的
`use crate::cutpoint::{Incremental, normalize, rank}` 全部變成未使用
警告——**切法引擎的東西 `Session` 一個都不再碰**。

### 什麼沒有拆

選字、詞庫修正、全半形、候選視窗**兩邊共用**。理由是真正不同的
只有「按鍵怎麼變成段落」這一件事——鎖定注音打完 `su3cl3` 之後要
選字，跟自動模式選字是同一回事。

拆到那一層的話，那十幾個方法要嘛重複一份、要嘛再抽第三個模組，
反而更繞。

### 新酷音的四格模型

注音音節有固定的四個位置，一個鍵按下去是**寫進它所屬的那一格**：

```text
打 ㄅ  →  [ㄅ][  ][  ][  ]
打 ㄆ  →  [ㄆ][  ][  ][  ]   ← 同一格，覆寫掉 ㄅ
打 ㄧ  →  [ㄆ][ㄧ][  ][  ]   ← 不同格，往下填
打 ˇ   →  完成，轉成字
```

好處是**打錯聲母直接打正確的就換掉**，不必先按 Backspace。
實作在 `core/src/bopomofo/buffer.rs`。

原始按鍵要跟符號**存在同一格**——覆寫時按鍵也要跟著換（打 `1` 再打
`q`，結算出去的該是 `q` 不是 `1q`）。

### 日文是第三條路，但簡單得多

查過 mozc 的 `CharChunk`，它是三層緩衝：

| 欄位 | 意思 | 打 `n` 時 |
|---|---|---|
| `raw` | 使用者實際打的字母 | `n` |
| `conversion` | **已確定**的轉換結果 | 空 |
| `ambiguous` | **還沒確定**的可能結果 | `ん` |
| `pending` | 等後續輸入才能決定 | `n` |

`ambiguous` 那層是為了處理 `n` 可能是「ん」也可能是「な」的歧義。
本專案規定**撥音一律打 `nn`**（見 §2.1 Phase 1），歧義不存在，
所以只要兩層：已轉的假名 + 還沒湊成 mora 的殘留字母。

而且**沒有覆寫**——羅馬字是線性序列，`ka` 的 `k` 跟 `a` 沒有
「格」的概念，打錯只能刪。所以 `RomajiInput` 比 `BopomofoInput`
單純很多，只做一件事：組字區顯示假名而不是羅馬字。

```text
打 s     → s        （還湊不出 mora）
打 u     → す
打 s     → すs
打 h     → すsh      ← 殘留字母原樣顯示，等後續
打 i     → すし
```

實作靠 `kana::to_kana_partial`——原本的 `to_kana` 是全有或全無
（`sush` 回 `None`），加一個「盡量轉」的版本：轉得出假名的前綴
轉掉，剩下的當 pending。

退格要注意**刪掉之後尾巴可能不成 mora**：`sushi` 刪掉 `i` 剩
`sush`，`sh` 要退回殘留區，不然切段會拿到不成 mora 的東西。

### 三條路的比較

| | Cascade（自動） | Bopomofo（鎖定注音） | Romaji（鎖定日文） |
|---|---|---|---|
| 累積方式 | 字串追加 | 四格覆寫 | 字串追加 |
| 組字區 | 原始按鍵 | 注音符號 | 假名＋殘留字母 |
| 何時算完一單位 | 不知道 | 按到聲調鍵 | 湊成一個 mora |
| 切法 | 多種 | 一種 | 一種 |

**鎖定英文沒有自己的路**——那是 passthrough，打什麼顯示什麼，
用 `Cascade` 加單語言切段就夠了（而且半形時根本不組字，見
[[語言鎖定：單引擎模式]]）。
