# 通譯輸入法 擴充包範本
#
# 複製這個檔案、改成你想要的名字，放進：
#
#     %APPDATA%\tsunagi-ime\packs\
#
# （這是預設位置。想放別的地方的話，設定頁的「擴充包」分頁可以改路徑。）
#
# 然後打開設定頁的「擴充包」分頁，按「重新整理」就會出現在清單裡，
# 勾起來就生效（不必重開輸入法，也不必重開正在打字的程式）。
#
# 檔名就是這個包的身分——設定檔記的是檔名，不是下面的 name。
# 所以取個好認的名字，之後改 name 也不會讓已啟用的包失效。


# ─────────────────────────────────────────────
#  這個包的基本資料
# ─────────────────────────────────────────────
#
# 全部可以省略——冒號後面留空就當作沒寫。
# 沒寫 name 的話，設定頁顯示的就是檔名（也就是你取的那個名字）。
# 只有檔案開頭這一段連續註解會被讀，遇到第一行詞就停。
#
# 填起來大概長這樣：
#
#     # name: Hololive 詞庫
#     # version: 1.2
#     # author: 你的名字
#     # description: VTuber 名字與常見的梗
#     # license: CC0
#     # updated: 2026-09-01
#     # homepage: https://example.com/packs

# name: 
# version: 
# author: 
# description: 
# license: 
# updated: 
# homepage: 


# ─────────────────────────────────────────────
#  詞
# ─────────────────────────────────────────────
#
# 每行三欄，用「Tab」分隔，不是空白。用空白會整行被忽略。
#
#     語言 <Tab> 輸入 <Tab> 輸出
#
# 第一欄有四種：
#
#   en   英文。打什麼就送出什麼，所以第三欄可以省略
#   ja   日文。第二欄寫平假名讀音，第三欄寫實際要送出的字
#   zh   中文。第二欄寫注音符號（不是鍵盤按鍵），第三欄寫詞
#   sym  符號。第二欄寫名字，第三欄寫一串符號——不分語言，
#        因為名字是「組出來的文字」，中文的「星」跟日文的「星」
#        本來就是同一個字串
#
# 幾件要注意的事：
#
#   - 注音要連著寫，一聲不標，其他聲調寫在該音節後面：ㄏㄨˊㄊㄠˊ
#   - 中文的字數要跟音節數一樣多，對不上的那行會被跳過
#   - 四種可以混在同一個包裡。「hololive」「ほろらいぶ」
#     「ㄏㄨˊㄊㄠˊ」是三種不同的打法，想三種都能打就三行都要寫
#   - 格式錯的那一行會被跳過，不會毀掉整個包
#   - # 開頭的是註解
#
# 符號怎麼用：打「\名字\」（前後各一個反斜線）就會換成第一個符號，
# 按方向鍵可以選其他的。名字是**組出來的文字**不是按鍵，所以中文、日文、
# 英文可以各給一個名字指向同一組符號：
#
#     sym	星	★☆✦✧⭐
#     sym	star	★☆✦✧⭐
#
# 打 \星\（注音）、\hoshi\（日文）、\star\（英文）都會出 ★。
#
#   - 第三欄一個字元就是一個候選，**順序就是候選的順序**，最常用的放第一個
#   - 放幾個都可以，沒有上限
#   - 名字可以是多個字（「星星」「左箭頭」都行），不必只有一個字
#   - 內建已經有一份常用的，包裡同名的會蓋過內建
#   - 只放符號、一個詞都沒有的包也是合法的包
#
# 下面是範例，把前面的 # 拿掉就會生效：

# en	hololive
# ja	ほろらいぶ	ホロライブ
# zh	ㄏㄨˊㄊㄠˊ	胡桃
# sym	星	★☆✦✧⭐
