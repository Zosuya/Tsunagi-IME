# 台語資料怎麼來

**原始 CSV 不進版控**——9 萬多筆的外部檔案，而且上游會更新。要用時重新下載。

但**產出的 `packs/台語.txt` 進版控**（1.7MB）：它是安裝時可勾選的元件
（`installer/tsunagi.iss` 的 `[Components]`），建安裝包時要抓得到。這跟
`data/` 底下那些詞庫不同——那些是「開發者的原料」，這份是「使用者拿到的
成品」。上游更新後重跑下面的步驟重產、commit 覆蓋即可。

## 一、下載台文華文線頂辭典

```powershell
curl -sL -o taihoa.csv `
  "https://raw.githubusercontent.com/ChhoeTaigi/ChhoeTaigiDatabase/master/ChhoeTaigiDatabase/ChhoeTaigi_TaihoaSoanntengTuichiautian.csv"
```

需要的欄位只有兩個：`HoaBun`（華語詞）與 `HanLoTaibunKip`（台語漢羅）。

### 授權：CC BY-SA 4.0

「姓名標示-相同方式分享」，**可以改作**（建包要把華語詞轉注音、篩選、
重排，每一項都是改作），而且跟專案的 GPL-3.0 相容。

CC BY-SA 的兩個條件都要照做，**包檔頭那幾行是授權的一部分，不是說明
文字，不可以拿掉**：

- **姓名標示**：鄭良偉教授（基礎資料）、楊允言教授與眾義工（增補校訂）
- **相同方式分享**：散布這份包時要標明它是 CC BY-SA 4.0

資料歸資料、程式歸程式——包的授權是 CC BY-SA 4.0，程式是 GPL-3.0，
各自獨立。

### 為什麼不用教育部台語辭典

它的品質最整齊（有審訂），但授權是 **CC BY-ND 3.0 TW**——**ND 是
「禁止改作」**。我們建包做的每一件事都是改作，而且 ND 跟 GPL-3.0
不相容（GPL 要求下游能自由修改）。**這條路封死，不是小心一點就好。**

同一個 repo 的其他辭典多半是 CC BY-NC-SA（非商業限制），也不能用。
9 份裡授權可用的只有台華線頂（CC BY-SA 4.0）、iTaigi（CC0）、
台灣白話基礎語句與台灣植物名彙（CC BY-SA 4.0，但量小且偏專門）。

## 二、量覆蓋率、順便產包

```powershell
cargo run --release -p ime-core --bin spike_taigi_cover -- taihoa.csv --pack packs\台語.txt
```

**包的格式是「華語國字 → 台語說法」**（`tw	沙發	膨椅`），不是注音。
段選單拿組字區選好的國字去查，歧義在選字階段就解掉了——用注音查會
撈到跨詞邊界的誤配（「沙發謝謝」冒出「發洩」，那兩個字沒在畫面上
相鄰過）。

2026-09-08 實測（91302 筆，去重後 49726 個華語詞）：

| | 條數 | 比例 |
|---|---|---|
| 純漢字華語詞 | 90995 | — |
| **可靠（引擎打得回原詞）** | **36987** | **74.4%** |
| 　整詞查得到讀音 | 32279 | 64.9% |
| 　逐字拼剛好對 | 4708 | 9.5% |
| 逐字拼錯了 | 9990 | 20.1% |
| 排序輸（按鍵對、引擎打出別的詞） | 2749 | 5.5% |

產出 **90995 行**，載入後 **49726 條**。

**上表的覆蓋率只是「這個詞打不打得出來」的參考，跟收不收進包無關**
——國字當鍵不必轉注音，每個詞都收得進來。舊版要「整詞查得到注音」
才收，那道關卡丟掉 20%（多半是多音字），條目從 49726 掉到 33149。

## 三、放進使用者的包資料夾

```powershell
Copy-Item packs\台語.txt "$env:APPDATA\tsunagi-ime\packs\"
```

**兩個地方都要放**：`packs\` 是內建的，`%APPDATA%\tsunagi-ime\packs\`
是使用者的。**同名時使用者的優先**——只更新 `packs\` 而忘了複製過去，
載進來的還是舊包（踩過：換了資料源測起來沒變，查半天才發現是舊包蓋著）。

在設定頁勾選「台語」就生效。打注音、**鎖定注音模式**、按 TAB：

| 鍵 | 做什麼 |
|---|---|
| **←→** | 跳到上／下一個詞（**跳過沒有台語說法的位置**）|
| **Shift+←→** | 調反白寬度（「我們」↔「我」）。**起點固定、只調長度** |
| **↑↓** | 在反白那個詞的台語說法之間選 |
| **Enter** | 定案，往下一個詞 |
| **1-9** | 直接選 |

反白單位是**詞**不是段——鎖定注音時整串是一段，反白整段沒有意義。
斷詞用**最大匹配**（見 `session::segmenu` 的 `tw_words`）：從左往右掃，
切過的不重複用，所以「沙發」佔掉兩格之後不會回頭試「發謝」。

## 已知限制

- **含羅馬字的條目照收**（`lóo力`、`seh-seh` 這種）——`HanLoTaibunKip`
  是漢羅混寫，那是資料本身的樣子，不是錯（使用者裁定保留）
- 覆蓋率的缺口（20.1%）多半是**多音字逐字拼錯**，要人工處理或放棄
- **沒有「你好」**——台語沒有對應的日常問候語，那是華語直譯。舊的
  iTaigi 包有「你好→出頭天」，那是眾包資料把華語詞欄填錯（第 427 筆），
  換成這份之後自然消失

## 換過資料源的紀錄

- **0.1（iTaigi，CC0）**：19046 筆 → 包 11919 行 → 載入 7402 條。
  眾包資料，有明顯錯條目（「你好→出頭天」）
- **0.2（台華線頂，CC BY-SA 4.0）**：91339 筆 → 包 67428 行 →
  載入 33149 條。**4.5 倍**，而且「沙發→膨椅」這種常用詞補上了

## 教育部那份差在哪（2026-09-08 量過，結論：先不用）

**只用台華線頂就好**，教育部那份等真的需要時再說。量出來的差異：

| | 華語詞數 |
|---|---|
| 教育部台語辭典 | 23839 |
| 台華線頂對照典 | **49811** |
| 兩份都有 | 16840 |
| 只有教育部有 | 6999 |
| 只有台華線頂有 | 32971 |

**教育部的價值不在收更多詞，在用字更準。** 它獨有的 6999 個大多是地名
（五城堡、月津港、鳥松跤）、機構名（北投溫泉博物館）、專門詞（磟碡、
箭筍、烏魚鰾），日常輸入用不太到。

真正的差別在**兩份都收的 16840 個詞裡有 10641 個（63%）說法不同**，
而且教育部有 7063 個台華線頂給不出的說法：

| 華語 | 教育部（審訂用字） | 台華線頂（眾包） |
|---|---|---|
| 早安 | **𠢕早** | gâu早 |
| 漂亮 | **媠** | suí |
| 腳踏車 | **跤踏車** | 腳踏車 |
| 可愛 | 古錐 | 古椎／古錐（兩種都收） |
| 手機 | 手機仔 | 手機 |

教育部是官方審訂的**推薦用字**；台華線頂是線上眾包編修的，用字不統一、
會夾羅馬字（`suí`、`gâu`）、也有華語字混入（「腳踏車」而非「跤踏車」）。

**取捨**：換過去會失去 33000 個詞，換來 7000 個更準的說法。而且教育部
那份是 **CC BY-ND（禁止改作）**——建包要拆欄、拆頓號、重排，都是改作。

**還沒查的退路**：ChhoeTaigi 標的是「照原本ê授權公開」，但原始出處是
教育部《臺灣閩南語常用詞辭典》。公務機關的資料常另有政府資料開放授權
（通常允許改作），跟這裡標的 CC BY-ND 未必相同。**真的要用時先查原始
網站現在標什麼授權**，別直接照 ChhoeTaigi 的標示下結論。
